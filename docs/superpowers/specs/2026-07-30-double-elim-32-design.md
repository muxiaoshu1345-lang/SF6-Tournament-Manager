# 32人淘汰赛赛制设计文档

## 概述

在现有CPT赛制（48人）基础上，新增"32人淘汰赛"赛制。两种赛制通过顶部切换开关选择，数据完全隔离，选手管理界面共享。

**核心定位：独立赛制模块，不影响现有CPT赛制代码。**

---

## 赛制流程

### 阶段1：初始配对
- 32人随机配对 → 16场比赛
- 16个胜者 → 胜者组
- 16个败者 → 败者组
- 确认时选择"是否8强随机对抗"

### 阶段2：胜者组单败
- 16人单败淘汰
- 若选择8强随机：打到4强停止
- 若不选择8强随机：打到冠军

### 阶段3：败者组单败
- 16人单败淘汰
- 若选择8强随机：打到4强停止
- 若不选择8强随机：打到冠军

### 阶段4A：8强随机对抗（选择8强随机时）
- 胜者组4人 vs 败者组4人（随机配对）
- 单败淘汰：4场 → 2场 → 决赛 → 冠军

### 阶段4B：总决赛（不选择8强随机时）
- 胜者组冠军 vs 败者组冠军
- 单场定冠军

## 数据模型

```python
state = {
    'current_format': 'cpt',   # 'cpt' 或 'double_elim_32'
    
    # CPT赛制数据（48人）
    'cpt': {
        'players': [],
        'pools': [],
        'groupStage1': {'locked': False, 'groups': []},
        'groupStage2': {'locked': False, 'groups': []},
        'elimination': {'locked': False, 'bracket': {}},
        'history': [],
        'historyIndex': -1
    },
    
    # 32人淘汰赛数据
    'double_elim_32': {
        'players': [],              # 32人名单
        'shuffle_top8': False,      # 是否8强随机
        'locked': False,
        'stage': 'setup',           # setup | round1 | bracket | final
        
        'round1': {                 # 第一轮：32人 → 16场
            'matches': []           # 16场比赛，产生胜者/败者
        },
        
        'winners': {                # 胜者组（16人单败）
            'players': [],          # 16人
            'r16': [],              # 8场
            'r8': [],               # 4场
            'r4': [],               # 2场（8强随机模式可跳过）
            'champion': None
        },
        
        'losers': {                 # 败者组（16人单败）
            'players': [],          # 16人
            'r16': [],              # 8场
            'r8': [],               # 4场
            'r4': [],               # 2场（8强随机模式可跳过）
            'champion': None
        },
        
        'final_8': {                # 8强随机模式
            'players': [],          # 8人
            'qf': [],               # 4场
            'sf': [],               # 2场
            'final': {},            # 决赛
            'champion': None
        },
        
        'grand_final': {            # 完整模式总决赛
            'winner_champ': None,
            'loser_champ': None,
            'match': {},
            'champion': None
        },
        
        'history': [],
        'historyIndex': -1
    }
}
```

## API设计

### 赛制切换
```
GET  /api/state                    # 返回完整状态（包含current_format）
POST /api/switch_format            # 切换赛制
```

### 选手管理（共享）
```
POST /api/players                  # 添加/删除/改名/分配池
POST /api/pools                    # 池管理
```

### 32人淘汰赛
```
POST /api/double_elim/randomize    # 随机初始配对
POST /api/double_elim/confirm      # 确认配对（传入shuffle_top8选项）
POST /api/double_elim/match/result # 录入比赛结果
POST /api/double_elim/shuffle_top8 # 8强随机配对
POST /api/double_elim/reset        # 重置
GET  /api/double_elim/state        # 获取32人淘汰赛状态
```

## 验收标准

1. 顶部切换开关可在CPT赛制和32人淘汰赛之间切换
2. 切换后Tab栏自动更新
3. 选手管理界面共享，但数据各自独立
4. 32人可随机配对成16场比赛
5. 确认配对时可选择"8强随机对抗"选项
6. 胜者组和败者组各自进行单败淘汰
7. 选择8强随机：打到4强后，8人随机配对淘汰
8. 不选择8强随机：两个组各自打完，冠军打总决赛
9. SVG对战图正确渲染
10. 撤销/重做正常工作
11. 数据自动保存
